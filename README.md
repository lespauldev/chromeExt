# Política de privacidad de GLB Cleaner

**Última actualización: 2 de noviembre de 2026**

GLB Cleaner es una extensión para Google Chrome que elimina elementos `DIV` de las páginas web cuando sus clases coinciden con las palabras que configura el usuario.

## Datos que procesa la extensión

- **Reglas de configuración:** las palabras o fragmentos de texto que el usuario introduce para identificar elementos.
- **Estado de la extensión:** si está activada o desactivada.
- **Contenido de las páginas:** mientras está activa, la extensión examina localmente los atributos `class` de elementos `DIV` para compararlos con las reglas. Si coinciden, elimina esos elementos de la página mostrada.

El examen se realiza en el navegador. GLB Cleaner no recopila ni almacena el contenido de las páginas, el historial de navegación, las direcciones visitadas, datos de formularios ni información personal de los usuarios.

## Almacenamiento y sincronización

Las reglas y el estado se guardan mediante `chrome.storage.sync`. Chrome puede sincronizar estos ajustes entre los dispositivos del usuario cuando la sincronización de Chrome está habilitada. El tratamiento de esa sincronización se rige también por las políticas y la configuración de privacidad de Google.

GLB Cleaner no envía estos datos al desarrollador ni a servidores externos operados por el desarrollador.

## Uso y divulgación de datos

La extensión utiliza las reglas y el estado únicamente para aplicar la configuración elegida por el usuario. No vende datos, no los utiliza para publicidad y no los comparte con el desarrollador ni con terceros.

## Permisos

GLB Cleaner solicita el permiso de almacenamiento para guardar y sincronizar las reglas y el estado. Sus scripts de contenido pueden ejecutarse en páginas web para revisar las clases de los elementos `DIV` y aplicar las reglas. La extensión no utiliza esa capacidad para recopilar o transmitir información de las páginas.

## Conservación y control

El usuario puede cambiar o borrar las reglas desde las opciones de la extensión. Al guardar la configuración sin reglas, la extensión deja de eliminar elementos. También puede desactivar la extensión desde su icono o desinstalarla. La disponibilidad o eliminación de los ajustes sincronizados puede depender de la configuración y las políticas de sincronización de Chrome.

## Privacidad de menores

GLB Cleaner no está dirigida específicamente a menores y no recopila deliberadamente datos personales.

Esta política podrá actualizarse si cambian las funciones o las prácticas de privacidad de GLB Cleaner. La fecha de actualización se indicará al principio de esta página.
